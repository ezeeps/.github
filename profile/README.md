# ☁️ ezeep

ezeep is a **cloud printing service** that connects users to office printers without installing local drivers. Printers, users, and rules are managed from a **web console**.

## 🚀 Why Choose ezeep?

Drivers are the main support burden in shared printing, and the service removes them from the endpoint. Rules decide who may use which device, so access follows the directory.

Everything is configured centrally instead of per laptop.

## 🎮 Why Use It?

- **Print without drivers**
- **Assign access** by group
- **Manage devices** centrally
- **Print from mobile**
- **Review usage**

## 🧩 Quick Start

1. Create the ezeep account.
2. Register printers in the console.
3. Connect the directory.
4. Set group access rules.
5. Install a client and print.
